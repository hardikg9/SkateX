# SkateX

Hosted pages for SkateLog (GitHub Pages: https://hardikg9.github.io/SkateX/).

| Path | What |
|---|---|
| `app/` | SkateLog app prototype (HTML), v0.3: phone sign-in (simulated code), roles (parent/guardian, adult skater, coach), consent, five tabs (Home, Plan, Skate, Insights, Learn; coaches get Club instead of Learn), stopwatch and manual sessions, AI coach (Elite, rule-based in the prototype), coach schedules, attendance, announcements, fee plans and extra fees. English; Hindi partial. Earlier versions: v0.1 commit 87a62ab, v0.2 commit b8d78bf. |
| `app/legal/` | Draft privacy policy and terms (not yet reviewed by a lawyer) |
| `skatesensor.html` | Sensor recorder page (two sensors at once) |
| `holyiot.html` | Holyiot factory-firmware recorder (historic) |
